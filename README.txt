So aktualisierst du die Webseite:
1. ZIP-Datei entpacken.
2. Den INHALT des Ordners „website-update-2026-08-01“ in deinen lokalen
   Webseitenordner ziehen.
3. Bei der Nachfrage „Zusammenführen“ und danach „Ersetzen“ wählen.
4. GitHub Desktop öffnen.
5. Unten links bei Summary schreiben:
   Add curated People Events Landscape and Street photos
6. Auf „Commit to main“ klicken.
7. Danach oben auf „Push origin“ klicken.
8. Nach einigen Minuten salgadophotography.ch neu laden.
